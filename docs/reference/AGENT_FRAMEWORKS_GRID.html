What the grid says

  • Closest to Pi Durable: TanStack AI (78%), then the Vercel AI SDK (70%). All three are libraries you embed, with any model, the loop outside the box and crash recovery. TanStack's recovery is built in; the AI SDK's needs Vercel Workflow.
  • Eve and Mastra are a pair (88%). Both are whole agent frameworks with sandboxes, approvals, schedules and evals. Those are Flockr's product, so they overlap Flockr more than they overlap Pi Durable (62 to 63%).
  • Closest to Flockr itself: Eve. It also has channels (Slack, Discord, GitHub), so it is part rival and part framework.
  • Furthest from everything: Claude Code. The only finished coding agent, tuned by Anthropic, but Claude only, no crash recovery, and it has to live inside the box.
  • Pi Durable vs TanStack AI on crashes: about equal on paper. Both rerun only tools marked safe and tell the model when a call was cut off. Pi Durable ships SQLite and file stores and saves your own state in the same write; TanStack ships only a memory store (you write the store for your database) but adds a lease and fence per thread for several servers. TanStack has an open bug where a reconnect during a long tool call writes the run twice (issue 2035).
